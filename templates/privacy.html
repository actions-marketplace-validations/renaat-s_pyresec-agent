Privacy Policy

Last updated: 15 September 2026 · NanoClone Life Sciences Ltd.

1. Overview

PYRESEC is an AI-powered code security auditing service operated by NanoClone Life Sciences Ltd. ("we", "us", "our"). This privacy policy explains what data we collect, how we use it, and your rights.

2. Data We Collect

Source code submissions: Code sent to our API endpoints for security analysis is processed in real-time and is not stored after the analysis response is returned. We do not retain, log, or aggregate your source code.

Wallet addresses: The x402 payment protocol records on-chain transaction data (payer wallet address, transaction hash, amount) which is public on the Base blockchain. We log settlement confirmations for revenue accounting.

IP addresses: Request IP addresses may be logged temporarily for abuse prevention and rate limiting. IP logs are rotated and deleted within 30 days.

No cookies: PYRESEC does not set any cookies. We do not use tracking cookies, session cookies, or advertising cookies.

No accounts: PYRESEC has no user accounts, login systems, or registration forms.

3. How We Use Data

Collected data is used solely for: (a) processing security analysis requests, (b) recording payment settlements for revenue accounting, (c) abuse prevention and rate limiting, and (d) maintaining service health and uptime.

4. Data Sharing

We do not sell, rent, or share your data with third parties. On-chain transaction data is publicly visible on the Base blockchain by design of the x402 protocol.

5. Data Retention

Source code: not retained. Payment records: retained indefinitely for accounting. IP logs: deleted within 30 days.

6. Security

All API communication occurs over HTTPS (enforced via TLS). We implement security headers including HSTS, Content Security Policy, and X-Frame-Options.

7. Your Rights

Since we do not store personal data beyond what is described above, there is no personal data to access, modify, or delete. Wallet transaction data is on-chain and controlled by the blockchain, not by us.

8. Changes to This Policy

We may update this policy from time to time. Changes will be reflected on this page with an updated date.

9. Contact

For questions about this policy, contact NanoClone Systems Ltd. via pyresec@nanoclonesystems.com.
